Arquitectura · Tema 2

Sistemas operativos

9 cuestionesArquitectura

Desde cero

Objetivo: Definir sistema operativo, kernel, sistema de ficheros y llamada al sistema, y saber las características de UNIX.

La idea

El sistema operativo es el intermediario entre el hardware y los programas. Reparte los recursos (memoria, CPU, periféricos, archivos) y ofrece servicios a las aplicaciones.

El núcleo

El kernel es el corazón: la parte que corre en modo privilegiado y la única que toca el hardware directamente. Las aplicaciones no pueden; tienen que pedírselo.

La llamada al sistema

Esa petición es la llamada al sistema. El programa se para, se guarda su estado en el PCB, el núcleo hace el trabajo y luego el programa sigue. Cuándo sigue lo decide el planificador de la CPU.

Truco para acordarte

Truco para la llamada al sistema: cuatro verbos en orden, «interrumpe, guarda, ejecuta, retorna». Si escribes los cuatro y nombras el PCB, la pregunta está completa.

Error típico

Decir que el sistema de ficheros «es el sistema operativo». Es una estructura de datos que organiza una partición. Y el kernel panic no es un error cualquiera: es uno del que el núcleo no puede recuperarse.

Las cuestiones del tema, respondidas

Intenta contestar cada una antes de abrir la respuesta. Lo que va en negrita son las palabras que no pueden faltar.

Cuestión 4

¿Qué es un Sistema Operativo?

✓Respuesta

Es el conjunto de programas informáticos que gestiona los recursos del hardware y proporciona servicios a los programas de aplicación. Es decir, es la interfaz entre el hardware y el software.

Suele ejecutarse en modo privilegiado respecto a los programas de aplicación.

Cuestión 5

Especifique las funciones esenciales de un Sistema Operativo.

✓Respuesta
  • Gestión de la memoria de acceso aleatorio.
  • Ejecución y planificación de procesos.
  • Asignación de recursos a las aplicaciones y procesos.
  • Gestión de periféricos de entrada/salida.
  • Gestión y automatización de usuarios.
  • Administración de archivos.

Cuestión 6

¿Qué es el núcleo o kernel de un Sistema Operativo?

✓Respuesta

Es la parte fundamental del sistema operativo, la que se ejecuta en modo privilegiado.

Facilita el acceso seguro al hardware, administra los recursos mediante llamadas al sistema y realiza las tareas de planificación.

Es el supervisor encargado de coordinar las operaciones del sistema operativo y garantizar un funcionamiento coherente y seguro.

Cuestión 7

Definir el concepto de Sistema de Ficheros.

✓Respuesta

Es una estructura de datos que se encarga de organizar los bloques y sectores de una partición de una memoria de almacenamiento masivo para poder almacenar archivos en ella.

Cuestión 8

¿Cuáles son las principales características de un Sistema Operativo tipo UNIX?

✓Respuesta
  • Multiusuario: cada usuario tiene su propia configuración y espacio de trabajo.
  • Multitarea: el sistema reparte los recursos de forma eficiente entre los procesos en ejecución.
  • Multiplataforma: puede ejecutarse en una gran variedad de hardware.
  • Interfaz de línea de comandos (CLI).
  • Modelo de archivos jerárquico.
  • Sistema de archivos estándar.
  • Programas y herramientas de código abierto.
  • Seguridad robusta.

Cuestión 9

¿Qué son los gestores de paquetes en Linux?

✓Respuesta

Son una colección de herramientas que automatizan el proceso de instalación, actualización, configuración y eliminación de paquetes de software.

Cuestión 10

Definir el concepto de Kernel panic.

✓Respuesta

Es el mensaje que muestra el núcleo del sistema operativo cuando detecta un error interno del que no se puede recuperar.

Suele dar información de depuración, útil solo para los desarrolladores del sistema operativo.

Cuestión 11

¿Para qué sirven las llamadas al sistema en Sistemas Operativos tipo UNIX?

✓Respuesta

Son el mecanismo de comunicación entre el sistema operativo y las aplicaciones: permiten que una aplicación solicite servicios al sistema operativo.

Las ejecuta el núcleo.

Cuestión 12

¿Cómo se gestiona una llamada al sistema en Sistemas Operativos tipo UNIX?

✓Respuesta
  1. La ejecución del programa que hace la llamada se interrumpe.
  2. Sus datos se guardan, normalmente en su PCB (Process Control Block, bloque de control de proceso), para poder continuar después.
  3. El procesador ejecuta las instrucciones de código de bajo nivel que realizan la tarea pedida.
  4. Al acabar, se retorna al proceso original, que continúa su ejecución.

El retorno no es obligatoriamente inmediato: depende del tiempo de ejecución de la llamada y del algoritmo de planificación de la CPU.
